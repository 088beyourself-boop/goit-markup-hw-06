# WebStudio

An independently completed responsive landing page based on a provided design.
This educational project was created as part of the HTML and CSS module at
GoIT.

## Features

- Semantic HTML5 markup
- Mobile-first responsive layout for mobile, tablet, and desktop
- Optimized images for standard and Retina displays
- SVG icon sprite
- Responsive mobile navigation
- Modal window with a contact form
- Hover and focus states with CSS transitions

## Technologies

- HTML5
- CSS3
- JavaScript
